# СМ ТЕХНО

Витрина запчастей, где покупатель подбирает позиции и обращается к менеджеру за ценой, наличием или условиями поставки.

## Язык

**Корзина**:
Список позиций и количеств, которые покупатель собирает для отправки менеджеру.
_Избегать_ заказа и оформления покупки.

**Заявка**:
Обращение покупателя к менеджеру. Может включать список запчастей из корзины.
_Избегать_ лида, заказа и брони.

**Быстрый контакт**:
Заявка из короткой формы. Список запчастей в ней необязателен.
_Избегать_ заказа звонка.

**Артикул**:
Код детали, в котором значимы ведущие нули. Один и тот же код может встречаться у разных брендов.
_Избегать_ номера товара.

**Дополнительный код**:
Справочное обозначение детали. Само по себе совпадение кода не подтверждает взаимозаменяемость.
_Избегать_ аналога.

**Цена по запросу**:
Обозначение позиции, для которой покупателю предлагают уточнить цену у менеджера.
_Избегать_ нулевой цены.
