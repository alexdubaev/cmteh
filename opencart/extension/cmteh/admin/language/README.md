# Русские тексты панели СМ ТЕХНО

Словари `ru-ru/` написаны для этого проекта: это оригинальные русские формулировки, без загрузки стороннего языкового пакета. Они распространяются на условиях **GPL-3.0-or-later**, совместимых с OpenCart (GPL-3.0). Имена ключей, маршруты и подстановки сверены с официальным исходным кодом OpenCart **4.1.0.4**, закреплённым в `packaging/open-cart.lock.json`. Это не перевод всего OpenCart: охвачены вход, шапка/меню/подвал, штатные товары/категории/производители, выбор изображений, общие кнопки, вкладки, пагинация и ошибки доступа.

Расширение регистрирует `admin/language/*/after`. Подпись loader 4.1.0.4: `route, prefix, code, output` по ссылке. Обработчик использует только закрытый перечень маршрутов; добавляет ключи через `language->set` и возвращаемый `output` с учётом prefix. Он не меняет `config_language`, `config_language_admin`, `config_language_id` и записи языков. Папка `ru-ru` служит внутренним источником текстов, устанавливать её как язык магазина не нужно. Названия и описания из БД остаются на прежнем языке данных. CKEditor/datepicker получают штатный код `ru` только для своего интерфейса.

Меню использует `admin/view/common/column_left/before` с подписью `route, data, code, output`. Добавление ссылок проверяет существующее `access` каждого конечного маршрута; серверные guards OpenCart и расширения остаются обязательными. Install/upgrade/uninstall управляют только собственными событиями; роли не дополняются, uninstall не удаляет данные каталога/заявок.

При обновлении OpenCart сравните ключи закреплённых upstream-словарей и подписи loader; сохраните типы/количество подстановок `%s`/`%d`. Добавьте перевод нового видимого ключа в соответствующий файл. На изолированной БД выполните проверку `admin_navigation` из `dev/release_checks.py` и короткий `tests/browser/admin-cms.mjs`, затем штатный строгий `bin/verify-local`. Отдельно проверьте, что язык данных и выдача существующих записей не изменились. Не заменяйте core-файлы и не добавляйте права группам через миграцию.
