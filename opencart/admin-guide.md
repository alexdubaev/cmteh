# Управление сайтом СМ ТЕХНО

Войдите в `/admin/` своей учётной записью. В левом меню откройте **СМ ТЕХНО** и нужный раздел. Ссылка содержит ваш текущий токен сессии: не передавайте её другим людям. Главная управления показывает только доступные разделы. Для повседневной работы не нужны список расширений, JSON или ручное редактирование базы.

## Где редактировать

| Элемент витрины | Источник истины | Раздел и действие |
| --- | --- | --- |
| Названия, артикулы, цены, остатки, статус товара | Штатные product/description/store + связанные данные cmteh_product с тем же native ID | **Товары** → запись; **Товары OpenCart** → та же запись для штатных полей |
| Бренд, основная и дополнительные категории, связанные товары, коды, характеристики | Связи native product и metadata СМ ТЕХНО | **Товары** → списки связей и обычные поля; SKU/MPN вводятся строкой, с ведущими нулями |
| Названия, иерархия, изображения категорий | Штатные category/description/path/store + cmteh_category | **Категории**; штатная форма **Категории OpenCart** сохраняет native ID |
| Бренды и логотипы, описание и SEO | Штатные manufacturer/store + cmteh_brand | **Бренды**; штатная форма **Бренды OpenCart** относится к тому же бренду |
| Шапка: логотип, телефон, email, реквизиты; контакты и общий подвал | Единственная запись site в cmteh_content | **Настройки сайта** → контакты, логотип, реквизиты, соцссылки, текст и подписи подвала |
| Ссылки шапки, разделы/юридические ссылки подвала | Записи navigation в cmteh_content | **Меню и подвал** → область, подпись, цель из списка или внешний URL, порядок, публикация |
| Главный баннер, заголовки/тексты/кнопки/изображения | Запись home в cmteh_content | **Главная страница** → соответствующие поля |
| Видимость и порядок блоков главной | home.home_blocks | **Главная страница** → включение блоков и порядок |
| Бренды и категории на главной | Опубликованный каталог + выбор и режимы home | **Главная страница** → автоматический/ручной выбор; корневые/все категории, лимит (0 — все); вложенные включаются явно |
| Карточки товаров на главной | Опубликованный каталог; выдача до 6 записей | **Товары** → содержание/статус; порядок и количество этой подборки пока задаёт шаблон выдачи |
| Статьи и анонсы главной | article в cmteh_content; главная показывает до 3 анонсов | **Статьи** → заголовок, дата, текст, изображение, статус, порядок, SEO |
| О компании, доставка, оплата, контакты | page в cmteh_content | **Страницы** → существующая системная запись, текст и разделы; адрес сохраняется |
| Вводные тексты каталога, брендов, статей, корзины | Системные page catalog/brands/articles/request | **Страницы** → соответствующая запись |
| Новые информационные страницы | page в cmteh_content | **Страницы** → добавить, заполнить визуальный редактор и SEO, опубликовать; затем добавить в меню |
| Каталог, фильтры и поиск | native каталог + проекция поиска cmteh_product | **Товары / Категории / Бренды** → данные; алгоритм поиска, набор фильтров и подписи интерфейса задаёт код |
| Корзина | Локальное хранилище браузера посетителя | Посетитель добавляет/удаляет позиции на витрине; админка не редактирует чужие корзины |
| Заявки и доставка уведомлений | cmteh_lead, lead_item, lead_outbox | **Заявки** → открыть номер; видны позиции и состояние отправки; SMTP настраивается при обслуживании |
| Адрес, meta title/description, canonical, индексируемость | Поля сущности и cmteh_route | Форма соответствующей записи → SEO; sitemap/robots и 301 формируются системой |
| Публичные изображения | image/catalog OpenCart; ссылки поля изображения | Выбор изображения в форме; отдельное право на **common/filemanager** |
| Одобренные приватные медиа | cmteh_media/media_link и закрытый каталог | Импорт с проверкой/одобрением; это отдельная операция обслуживания, доступа через обычный публичный файл нет |

## Мобильные действия для покупателей

На телефоне нижняя панель предлагает «Позвонить» и «Запрос», а корзина со счётчиком остаётся отдельной ссылкой в шапке. Телефон для звонка берётся из **Настройки сайта**; если значение пустое или некорректное, ссылка ведёт на страницу контактов. Короткий запрос содержит имя, телефон и необязательный комментарий и отправляется отдельно от выбранных товаров. Он не очищает корзину. Для заявки с товарами посетитель открывает корзину. Подтверждение на витрине отражает ответ существующего сервиса заявок и не обещает доставку письма или срок ответа менеджера.

Коммерческие данные не создаются переводом или обновлением. Стартовые контакты/тексты/ссылки из прежней витрины переносятся в записи только при первоначальной миграции; последующие обновления сохраняют пользовательские изменения. Сверьте их с утверждёнными владельцем данными перед публикацией. Демо Cameras/Components — штатный пример OpenCart, а не ассортимент СМ ТЕХНО. Технические названия кнопок, SVG-иконки, макет, лимиты выдачи товаров/анонсов и алгоритмы поиска остаются кодом. Не выдавайте их за редактируемый коммерческий контент.

## Обычный маршрут владельца

1. **Категории / Бренды** → найдите запись по названию, измените название, сохраните. Откройте витрину и перезагрузите страницу. Имя само по себе не меняет адрес.
2. **Товары** → добавьте запись, выберите бренд и категории, задайте артикулы, изображение и режим цены, заполните описание и SEO. Сохраните черновик. После проверки опубликуйте и проверьте карточку и поиск на витрине.
3. **Главная страница** → выберите порядок/видимость блоков, режим и список брендов/категорий. Сохраните и проверьте `/` после перезагрузки.
4. **Страницы / Статьи** → редактируйте текст, изображения и разделы визуальным редактором. Черновик доступен только в авторизованной панели; публичная ссылка появляется после публикации. Для опубликованной записи есть переход на витрину.
5. **Меню и подвал** → выберите опубликованную цель из списка, задайте подпись и область. **Настройки сайта** → измените общие контакты/реквизиты, затем проверьте шапку, контакты и подвал.
6. **Заявки** → откройте номер, сверьте позиции и состояние уведомления. История заявок сохраняется при обновлении.

Чтобы временно убрать материал, выберите черновик/архив и сохраните. Для возвращения — публикацию. Смена адреса выполняется отдельно и требует явного подтверждения; старый адрес получает прямой 301 при допустимой смене. Коллизии и зарезервированные маршруты отклоняются. Физическое удаление необратимо через форму: сначала сохраните нужные данные, удаляйте только точно выбранную запись. Связанный бренд/категорию нельзя удалить до снятия зависимостей, системные записи защищены. Удалённая запись возвращает 404/410; она не отправляет все старые ссылки на главную. Позиции в поисковых системах не гарантируются.

## Права без автоматического расширения ролей

Администратор открывает **Система → Пользователи → Группы пользователей** и назначает только согласованные права. Установка/обновление модуля не выдаёт дополнительных разрешений. `access` разрешает открыть раздел, `modify` — изменить данные. Ссылка на главную управления необязательна для работы прямого меню.

| Роль | Access | Modify |
| --- | --- | --- |
| Оператор каталога | extension/cmteh/module/cmteh_catalog; при необходимости extension/cmteh/module/cmteh | extension/cmteh/module/cmteh_catalog |
| Штатное редактирование каталога (дополнительно оператору по задаче) | catalog/product, catalog/category, catalog/manufacturer | Те из этих маршрутов, которые разрешено изменять |
| Выбор изображений (отдельно) | common/filemanager | Только если разрешены загрузка/удаление через штатный менеджер |
| Менеджер заявок | extension/cmteh/module/cmteh_leads; при необходимости extension/cmteh/module/cmteh | Не требуется |

Право обслуживания `modify extension/cmteh/module/cmteh`, установки, управления пользователями остаётся у назначенного администратора. Не включайте все разрешения группе ради видимости одной ссылки. Если пункт отсутствует или экран пишет «Доступ запрещён», администратор проверяет конкретный конечный маршрут. При наличии доступа к управлению группами главная модуля показывает диагностическую ссылку; она не изменяет разрешения.

## Что установлено по окружениям

Read-only исследование закрытого REG.RU от 10.11.2026 зафиксировало 35 native товаров / 16 mapped, 46 native категорий / 8 mapped, 17 native производителей / 11 mapped; также 8 страниц и 2 статьи. Отсутствующих native объектов у этих сопоставлений — 0. Все 45 mapped адресов отвечали HTTP 200 на авторизованный HEAD. Это доказательство наличия и доступности адресов, а не браузерная приёмка нового редактора или коммерческой корректности содержимого.

В браузере стенда штатные списки товаров/категорий/производителей доступны, меню было английским. Вход существующего пользователя работает, но редактор СМ ТЕХНО возвращает штатный Permission Denied: у группы есть только `extension/cmteh/module/cmteh`, нет `extension/cmteh/module/cmteh_catalog` и `extension/cmteh/module/cmteh_leads`. Разрешения стенда не менялись. Локальные проверки создают отдельные синтетические роли с нужными маршрутами; штатная установка/upgrade их не раздают. Это не доказывает наличие этих прав у пользователя хостинга. Изменение прав стенда — отдельное защищённое действие.

| Окружение | Фактическая граница доказательств |
| --- | --- |
| localhost, изолированные синтетические БД | Проверки записываются текущим строгим `verify-local` в private runtime/evidence/release.json; наличие кода не означает PASS. Не применять результаты старого пакета к новому исходнику |
| Закрытый REG.RU | Read-only baseline выше; MySQL 5.7.44-48, CLI PHP 8.2.35; web PHP отдельно не сверено. Новая версия админки туда не установлена, сценарии её форм NOT RUN |
| production cmteh.ru / engine.cmteh.ru | Не менялись; перенос, реальные заявки, DNS и переключение не входят в эту приёмку |

Совместимость локального MySQL 8 не заменяет проверку отдельного MySQL 5.7 и конкретного тарифа хостинга. Нагрузка, SMTP-доставка и реальный утверждённый каталог остаются NOT RUN до подтверждённого протокола. Публичная репетиционная выборка StoreLand не подтверждает цены, остатки или право публикации фотографий.

## Обновление и восстановление

Процедура и границы backup/restore: [README](README.md#обновление-резервная-копия-и-восстановление). До обновления сохраните предыдущий пакет и SHA, базу, публичные изображения и закрытые конфиги/медиа. Репетиция восстановления выполняется на отдельной БД/каталоге. Старый снимок нельзя накатывать поверх свежих заявок: сначала снимок текущих данных и сверка новых записей/позиций/очереди. После установки файлов администратор открывает **Главная → Обслуживание расширения → Применить миграции**; это повторяемая операция, пользовательские записи и роли сохраняются. Перезагрузите страницу, проверьте меню, записи и витрину. Удаление модуля снимает собственные events/маркер активности, сохраняя каталог и заявки; оно не является удалением данных.

Русские формулировки оригинальные, без стороннего пакета. Совместимость закреплена на OpenCart 4.1.0.4; происхождение, лицензия и обновление словарей описаны в [language/README](extension/cmteh/admin/language/README.md). Перевод не меняет язык данных/витрины и не требует создавать русский language ID.
