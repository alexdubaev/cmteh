# Данные каталога СМ ТЕХНО

`demo.ndjson` — синтетическое зеркало демонстрационной витрины. В файле 49 записей, включая 16 товаров, 11 брендов, 8 категорий, настройки, меню и статью. Телефон и адрес на example.test предназначены для демонстрации. Цены и наличие относятся к тестовым карточкам.

Каждая строка UTF-8 NDJSON содержит объект с ключами `type` и `data`. Допустимые типы: `brand`, `category`, `product`, `site`, `home`, `navigation`, `page`, `article`, `media`, `route`, `unpublish`. Сначала передавайте бренды и категории, затем ссылающиеся на них товары. Поле `id` — стабильная строка источника. `slug` задаёт публичный адрес. `sku` и `mpn` передавайте строками. Состояния цены и наличия независимы. `status` принимает `draft`, `published` или `archived`. При пропуске статуса запись остаётся черновиком. `published_at` — дата UTC в формате ISO 8601. Фиксированная цена требует неотрицательной суммы и кода валюты, а нулевая ещё и `confirm_zero_price: true`.

Каталог сопоставляет идентификаторы источника со штатными ID товаров, производителей, категорий и характеристик OpenCart. Поля цен, заголовков и основных описаний доступны через админку OpenCart по маршруту `extension/cmteh/module/cmteh_catalog`. Этот редактор обновляет поисковый индекс вместе с данными. Сложные поля карточки и дополнительные секции редактируются в разделе «Дополнительные поля и связи». Роли оператора и менеджера настраиваются штатными группами OpenCart.

Медиа загружаются отдельно в `<CMTEH_PRIVATE_DIR>/media`. Запись `media` задаёт `uuid`, относительный `path`, `filename`, `mime`, `status` и список `owners` с объектами `{type,id}`. Публикация возможна только для разрешённого локального формата и файла, находящегося внутри каталога медиа. Исходные картинки и разрешённые миниатюры подготавливаются вне сайта. Заявки и личные данные клиентов в этот формат не входят.

Старая ссылка передаётся отдельной записью `route`. Поля `path` и `target` содержат полные внутренние пути. `status: 301` требует точного целевого пути, а `status: 410` относится к удалённому материалу. Публичная маршрутизация дополнительно проверяет существование цели.

Предпросмотр выводит SHA-256 входного файла, числа добавлений, обновлений, пропусков и ошибок и до 250 диагностик с номерами строк. Проверьте отчёт, затем запустите применение с тем же SHA-256 и новым `--run-key`.

```bash
php cli/import-catalog.php --config=/path/to/opencart/config.php --input=/private/catalog.ndjson --preview
php cli/import-catalog.php --config=/path/to/opencart/config.php --input=/private/catalog.ndjson --apply --confirm=<SHA256> --run-key=<RUN>
```

Для продолжения того же файла и прогона передайте `--resume` с тем же ключом и SHA-256. Запись о контрольной точке фиксируется в одной транзакции с данными пакета. Если часть товаров отсутствует в файле, их статус сохраняется. Для массового снятия с публикации передайте отдельный файл с записями `unpublish` и исходными `id`, а также флаг `--allow-unpublish` на предпросмотре и при применении подтверждённого файла.

Набор для измерений генерируется локально. Он содержит 100 000 товаров с различными брендами, категориями, характеристиками, статусами, ценами, валютами и 5 000 JPEG. Запускайте генератор для нового пути вывода и пустого частного каталога медиа.

```bash
php cli/generate-catalog.php --output=/private/scale.ndjson --media-dir=/private/media
```
