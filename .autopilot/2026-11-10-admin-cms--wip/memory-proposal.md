# Предложение к AGENTS.md (файл владельца не изменён)

- Для изменений `opencart/` использовать PHP/OpenCart gate из `opencart/README.md`; корневой Next.js verifier относится к эталону, а не доказывает готовность PHP-версии.
- Маршрут владельца и карта данных: `opencart/admin-guide.md`; границы: `docs/architecture.md`; язык/ACL: ADR0004.
- Перевод админки не меняет язык данных. Начальный default language загружен до DB events; общие ключи накладываются позднее.
- Установка/upgrade не раздают права редактора и заявок. Локальные проверки создают собственные синтетические роли; наличие таких ролей не доказывает права администратора хостинга.

## Правка без автопилота

Перед следующей правкой прочитать `.autopilot/PROGRESS.md`, проверить локальную историю после последней сборки; после правки записать фактический результат и открытые ограничения. Не переносить незавершённые требования в «готово».

## История git

История требования ищется по трейлеру `Requirements:`; номер таска имеет смысл только вместе с `Autopilot-Run:`. Ветки, проверки и публикация подчиняются текущим прямым правилам владельца.

- OpenCart Twig adapter работает с autoescape=false. Каждый included storefront template сам объявляет html autoescape; ui macros импортируются в каждом потребителе. Parent block/import не наследуется include. Проверять фактические карточки и текстовые/атрибутные CMS values в браузере.
