# Главная и переходы V2

## Задача

Кнопки и ссылки на локальной главной открывают соответствующие разделы V2. Движение при выходе и возвращении следует уже работающему сценарию списка.

## Решение

- R01–R02. Проверить направления всех ссылок главной, включая меню каталога, категории и бренды, логотипы партнёров, строку и пример поиска, список, корзину, основное меню, подвал и контакты. Реальные ссылки на каталог ведут в каталог V2, а поиск сохраняет текущее поведение для одного и нескольких результатов. Телефон, почта, ссылки наружу, якоря, переключатели и быстрый запрос сохраняют свои действия.
- R03. После поиска и открытия товара возврат по логотипу перемещает ту же строку поиска в центр без обратного скачка. Чертёж экскаватора сохраняет геометрию между кадрами или изменяет её непрерывно. Особенно проверить длинную карточку, у которой ширина или высота стадии отличается от главной.
- R04. Логотипы открывают страницу выбранного бренда через тот же механизм раскрытия, который работает для списка. Логотип компании возвращает из бренда в главную.
- R05. Внутренние страницы, на которые ведёт главная, раскрываются при обычном клике. При возврате сохраняется плавность и история. Плавное возвращение по логотипу проверяем из выдачи с несколькими результатами, карточки, бренда и списка. Раскрытие списка проверяем в обоих направлениях. Прямые URL, обновление, клавиатура, открытие в новой вкладке и системная настройка уменьшения движения продолжают работать штатно. Неудачная загрузка предлагает существующий способ повторить переход.

## Решения по реализации

Применяем серверный HTML и повторно используем оболочку V2. Движение связано с визуальными границами поиска и фона, а не с высокой карточкой товара. Для корзины и контактов сохраняем штатную загрузку формы, добавляя браузерное раскрытие V2 при поддержке межстраничного перехода. В прочих браузерах эти страницы открываются штатно. Назначения из CMS, доступность и изменения состояния через существующие модули — часть приёмки.

## Границы

Только локальная V2. Домен V1, его оформление и работа, маршруты сервера, данные и API не меняются. Новых зависимостей нет. Один связанный таск и одна приёмка.
