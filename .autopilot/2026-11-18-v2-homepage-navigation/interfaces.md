# Границы, решённые в спецификации

- V2 layout сохраняет отдельный вид и постоянные поиск, меню и фон. V2 navigation отвечает за выбор маршрута, получение и проверку HTML, историю и раскрытие. Ошибки, редиректы и обычные браузерные способы открыть link сохраняются.
- Формы и корзина используют существующие модули и контракты. Между переходами не должно появляться повторных обработчиков, двойной отправки, сброса FileList или устаревшего показа корзины.
- V1/runtime не трогаем. Общий интерфейс инициализации допустим лишь при сохранении прямого V1/V2 поведения и с проверкой на целевом сценарии.
- Тестовый runtime 3188, локальная V2 владельца 3162. Тестовый браузер проверяет маршруты, общий DOM, начало и конец движения, функциональные действия, уменьшение движения и Back/Forward.
- Chrome поддерживает opt-in межстраничных переходов для same-origin. Нативные формы используют их как браузерное улучшение. CSS должен учитывать reduced motion и сохранять рабочую загрузку в браузерах без этой возможности.
- Направленная проверка: в тестовом runtime обновить overlay через v2-local.py refresh, затем CMTEH_BROWSER_BASE=http://127.0.0.1:3188 node opencart/tests/browser/v2-navigation.mjs. Один сценарий передаётся аргументом. CMTEH_BROWSER_TOOLING=D:/codex/cmteh даёт доступ к имеющемуся Playwright. HTTP/package: v2-check.py --http-only. Перед публикацией обязателен корневой verify-local.mjs.
