# Главная V2 — локальная проверка

- Поиск, меню и фон остаются на месте при переходах V2. Раскрытие и сворачивание учитывают настройку уменьшения движения. История браузера, формы и корзина сохраняют существующее поведение. Проверка ограничена локальной V2 и её интерфейсом.
- Тестовый runtime использует порт 3188. Запуск и обновление overlay выполняются командами `v2-local.py start` и `v2-local.py refresh`. Chromium проверяется из корня репозитория:

```powershell
$env:CMTEH_BROWSER_BASE = 'http://127.0.0.1:3188'
$env:CMTEH_BROWSER_TOOLING = 'D:/codex/cmteh'
node opencart/tests/browser/v2-navigation.mjs
```

В чистом checkout прошли 30 адресов главной и 10 сценариев, включая уменьшение движения и геометрию в обычном и мобильном окнах браузера.
