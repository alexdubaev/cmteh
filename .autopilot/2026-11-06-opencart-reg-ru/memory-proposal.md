# Предложение для AGENTS.md

- PHP-кандидат находится в opencart/ и проверяется отдельным gate из opencart/README.md; штатный Next.js gate остаётся проверкой эталона.
- При исчерпанных Docker address pools у первого запуска задайте свободный частный CMTEH_DOCKER_SUBNET. Существующие сети проекта не менять.
- Для полного публичного пути читайте исходный REQUEST_URI сервера. OpenCart Request экранирует &, а Apache mod_dir пытается добавить слеш к физическому /catalog.
- Заявки, почта, лицензии и доступы проверяются на изолированной синтетической базе. Чистая проверка тестирует capture вместо исходящей почты.

### Проверка OpenCart

- Команда из корня репозитория с аргументами из `opencart/README.md` прошла в свежем клоне коммита `343e9cc`. Укажите проверенный ZIP, новый runtime вне checkout, 18 снимков эталона, checkout с установленным Playwright из того же lockfile и свободный loopback-порт. `--browser-tooling` можно опустить при установленном Playwright в текущем checkout.

```powershell
python opencart/bin/verify-local --upstream <OFFICIAL_ZIP> --runtime-dir <NEW_PRIVATE_RUNTIME> --reference-dir <REFERENCE_PNG_DIR> --browser-tooling <LOCKED_TOOLING_CHECKOUT> --port 3156
```

- `node scripts/verify-local.mjs` отдельно прошёл в зафиксированном Next.js эталоне `61a10e2` с приватным чистым клоном CMS. Настройка — в корневом `README.md`.
- `docs/architecture.md` связывает точки входа OpenCart, публичное чтение, импорт, заявки и закрытое хранение. Порядок установки и восстановления — `opencart/README.md`.

### Правка без автопилота

- Перед правкой прочитайте `.autopilot/PROGRESS.md`, затем посмотрите изменения после последней сборки. Для затронутого решения откройте `docs/adr/`, для терминов — `CONTEXT.md`, для требований — `manifest.md` из папки сборки, указанной в `PROGRESS.md`.
- После правки добавьте в «Правки без автопилота» запись с датой, изменением и причиной. Закройте исправленные пункты и запишите подтверждённые владельцем договорённости его словами.

### История git

- Изменения после последней сдачи показывает `git log --oneline "$(git log -1 --format=%h --grep='^Autopilot: сборка сдана')"..HEAD -- . ':(exclude).autopilot'`.
- Для истории требования выполните `git log --oneline --grep='R02'` с нужным ID из манифеста. Для истории файла выполните `git log --oneline -10 -- <файл>`.
- Заголовок коммита описывает изменение, тело объясняет причину. Для требования из манифеста добавьте трейлер `Requirements: R02` с его ID. Заголовок `Autopilot: сборка сдана` зарезервирован для итогового коммита Autopilot.
