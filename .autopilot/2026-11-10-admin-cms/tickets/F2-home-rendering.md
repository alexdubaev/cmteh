## Что должно заработать
Ручной просмотр release candidate-home1440/390 обнаружил пустые product/article grids при живых опубликованных данных. Parent home.twig импортирует ui, но Twig macros локальны шаблону; два includedpartials вызывают ui.card/ui.articleCard без собственного импорта. Кроме того, OpenCart adapter default autoescape=false (upstream library/template/twig.php:107), а прежний autoescapehtml родителя не наследуется includedpartials. Восстановить прежнее полное безопасное отображение без изменения данных/дизайна/URL/доменных правил.

## Критерии приёмки
- [ ] На fixture homepage фактически видны6карточек товаров и2карточки статей с корректными ссылками, не только пустые grids/заголовки.
- [ ] Все7новых homepartials явно используют html autoescape; product/article импортируют нужные ui macros локально. Санитизированный rich content сохраняет существующий вывод.
- [ ] В настоящем браузере безопасный локальный probe разметки в home text/attribute не создаёт DOM-элемент/обработчик и не исполняется; текст/alt отображаются экранированно. Значения после теста восстановлены. Не использовать внешние адреса или извлечение данных в probe.
- [ ] Регрессии RED до правки, GREEN после; complete browser group7+новаяhomeграница и targeteddesktop/mobile screenshot проверены. Никаких правокядра, тестового обхода, ослабленияHTMLsanitization или фактических коммерческих данных.
