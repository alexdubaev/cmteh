## Критерии приёмки
- [ ] category.h1 и article.excerpt действительно сохраняются и читаются на публичной границе/витрине.
- [ ] Несвязанные CMS-сохранения сохраняют независимый native product.model при отличающемся SKU, в том числе после native edit.

- [ ] Социальная aria-label — валидный UTF8 и понятный русский текст.
- [ ] Новые meaningful regressions сначала RED по причине дефекта, затем GREEN; affected native browser/API и текущие административные DB границы зелёные. Без второго whole-change review и без полного generic gate до source freeze.

## Закрытие реального сбоя выпускного gate
Внешний декоративный Google CSS воспроизводит timeout10s, поэтому только два точных font-хоста изолируются в функциональном браузере; проверки приложения не подменяются. Слепая приёмка выявила конфликт ID между новым и основным сценарием после удаления410: каждое create получает отдельный ID/slug. Требуются все6основных групп и reviewclosureGREEN; generic mode остаётся full.

Слепая приёмка дополнительно воспроизвела повреждённый PNG в существующем opt-in HTTP fixture: файл присутствует/разрешён, но GD отклоняет байты. Исправить только fixture на валидный маленький PNG; HTTP200/404/доступ/legacy assertions не менять. Проверить полный opt-in HTTP scenario на изолированном fresh стенде и очистить только собственную fixture.

Уточнение причиныHTTP404: stream передаёт исходный файл безGD; отказ вызван root-owned0750media при CLIseed. Невалидный PNG —отдельная ошибка fixture. Точная воспроизводимая командаseed/clean использует www-data и документируется; доступ/права приватных файлов не ослабляются.
