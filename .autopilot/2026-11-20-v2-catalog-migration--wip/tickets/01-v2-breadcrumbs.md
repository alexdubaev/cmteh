## Что должно заработать

Карточка V2 показывает переходы по всем опубликованным предкам основной категории. BreadcrumbList следует видимой цепочке, последний элемент указывает canonical товара. Для карточки без категории применяется текущий путь через бренд.

## Из брифа

> «с этих проектов взял товары с ценами картинками, описаниями, хлебными крошками»

## Приёмка

- [ ] В карточке с вложенной категорией видны оба звена и рабочие ссылки. Последний элемент — артикул.
- [ ] JSON-LD совпадает с цепочкой, каждый item использует правильный адрес.
- [ ] V1 и исходный общий OpenCart template продолжают выдавать прежний HTML и разметку.
- [ ] Отсутствующая категория, скрытая категория и повреждённая цепочка не порождают неверные ссылки или зацикливание.
