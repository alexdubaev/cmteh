# Перенос каталога в СМ ТЕХНО V2

Клиент находит запчасть из CatPart или Deere Shop, видит исходную коммерческую информацию и может открыть карточку по сохранённой ссылке старого cmteh.ru.

| Метка | Результат | Приёмка |
|---|---|---|
| R01 | Товары из alexdubaev/JD-landing и alexdubaev/cat-part | Опубликованные записи из двух указанных проектов. Полнота по источнику и правилу отбора проверена по URL, бренду, SKU и исходным ID. Пропуски перечислены. Подходящие карточки без публичного URL, если обнаружатся, отдельно показать владельцу. |
| G01 | Deere Shop только с фотографиями | Товар проходит отбор, если у него есть реальное исходное фото. Заглушка не считается. Сверить количество с ориентиром владельца около 280 и объяснить расхождение. |
| R02 | Опубликованные цены | Сумма и валюта совпадают с публичным источником. Явное «по запросу» сохраняется. Неоднозначные, нулевые или недоступные значения уточняются. Наличие по цене не выводится. |
| R03 | Фото | Сохранить доступные публичные изображения и их роли в карточке и галерее. Сверить привязку к исходной карточке, тип файла и отображение на V2. Пустые фото и заглушки записать отдельно. |
| R04 | Описания | Перенести опубликованные короткие и полные описания с допустимым форматированием OpenCart. Отсутствующие тексты не дополнять догадками. |
| R05 | Хлебные крошки | Для каждой исходной карточки сопоставить каждое звено её крошек с категорией V2. На V2 воспроизвести проверенную цепочку предков в том же порядке, согласовать её с BreadcrumbList и проверить целевые ссылки. Для товара без категории сохраняется путь через бренд. |
| R06 | Товары в нужных разделах V2 | Каждая карточка доступна в соответствующей категории и по бренду. Существующие позиции сопоставлять по доказанной идентичности, сохраняя адрес и складские предложения. Конфликты категории, цены, бренда или SKU уточнять. |
| R07 | Проиндексированные страницы старого cmteh.ru доступны | Проверить 191 точный URL Яндекса и 503 адреса публичной карты. Сохранить путь с HTTP 200 либо один 301 на подтверждённый эквивалент с HTTP 200 и собственным canonical. Для 22 текущих 404 применить одобренное правило: точное совпадение получает 301, у остальных без страницы либо архива сохраняется 404. Проверить адреса вне карты, пагинацию и метки отслеживания. |
| R08 | Пробелы и сомнения разрешаются владельцем | Вопрос содержит конкретный URL или артикул и отсутствующее поле либо конфликт. Записи с неподтверждёнными данными не подменять. |

## Реализация

Использовать действующий OpenCart и его штатный импорт. Данные и изображения подготавливаются вне Git с контрольными суммами. Порядок импорта учитывает ссылки товаров на категории и изображений на владельцев. Репетиция проводится в отдельном локальном V2. Проверяются повторный запуск, цены, изображения, крошки, канонические и старые URL.

Когда окружение для применения подтверждено, сверить существующий каталог и доказать, что обратное изменение затронет только записи и изображения миграции и сохранит новые заявки. Основной домен, DNS и сайты-источники не меняются. Сверить все обнаруженные адреса обоих поисковиков, текущей карты и архивной ведомости. Google Search Console сейчас недоступен через подключённые инструменты. По Яндексу и публичным картам есть проверяемый список. Полнота Google требует подтверждённой выгрузки.
